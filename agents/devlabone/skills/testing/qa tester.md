# Regression Testing

Ensure new changes do not break existing features.

Example:

```
New Feature Added

        |

Run Existing Tests

        |

Confirm Stability
```

---

# Smoke Testing

Quick validation after deployment.

Checks:

- Application starts
- Main features work
- Environment is healthy

---

# Sanity Testing

Focused testing after small changes.

Example:

```
Payment Bug Fixed

        |

Test Payment Flow Only
```

---

# Exploratory Testing

Unstructured testing.

Tester explores:

- Unexpected flows
- Edge cases
- User behavior

---

# Negative Testing

Test invalid scenarios.

Examples:

- Wrong password
- Invalid input
- Missing fields
- Network failures

---

# Boundary Testing

Test limits.

Example:

Age field:

```
Minimum:18

Maximum:60
```

Test:

```
17

18

60

61
```

---

# Equivalence Partitioning

Divide inputs into groups.

Example:

Age:

```
Invalid

0-17


Valid

18-60


Invalid

61+
```
